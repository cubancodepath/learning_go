# Learning Go

This repository contains my progress, source code, exercises, and notes generated while reading and following the book **Learning Go**.

## Repository Structure

The code is mainly organized by chapters, which makes it easier to navigate and review the different concepts of the Go programming language:

- **`chapter_2/`**: Primitive types and variable declarations.
- **`chapter_3/`**: Composite types (Slices, Arrays, Maps, Structs, and Runes).
- **`chapter_4/`**: Blocks, Variable Shadowing, and Control Structures (for, switch, if).
- **`chapter_5/`**: Functions, closures, and basic error handling.
- **`chapter_6/`**: Pointers and how Go manages memory.
- **`chapter_7/`**: Types, Methods, and Interfaces (Object-Oriented Programming in Go).

## How to run the code

To test the code from any chapter, make sure you have Go installed on your system. Then, navigate to the corresponding directory and run the main file:

```bash
# Example to run the code from chapter 7
cd chapter_7
./chapter_7
```
